# CQWE V4.5 — Copernican competition cycle / safe D-drive disk governance

Installation (double-folder layout): `D:\CQWE_MASTER_V45\CQWE_MASTER_V45\RUN_ONCE_V45.ps1`.

## Scope
- Reads existing validated real-market public four-asset L2+trade captures, separately by asset and session.
- Competes six pre-registered dendritic genotypes against transparent MM-inspired **policy proxy** baselines: no-trade, always-cross-long, L2 imbalance filter, trend+L2 agreement, and stylized inventory-skew quote preference.
- Separates train/heldout in each existing capture replay. It does **not** constitute independently precommitted live OOS evidence or an executable account result.
- Does **not** identify actual market makers; passive market-maker queue positions, private inventories, fills and cancels are unavailable from public MBP data. The stylized inventory skew benchmark deliberately reports future mid-quote markouts, **not maker fill returns**.
- Adds 15 focused adversarial unit cases including immutable hash chain, no future leakage, non-overlap, replay-only promotion lockout, zero-fill claims, changed cache refusal, and protected evidence.
- Dry-run storage inspection on `D:\CQWE_DATA\pycache`: only files ending `.pyc` older than seven days are eligible for explicit deletion with `--apply-pyc-only`, never automatically; raw L2 `.jsonl`, model evidence, reports, cash ledgers, checksums, and logs are never deletable through this code. No automated deletion task.
- One Windows install command. Does not overwrite existing Git files, mutate old data, touch Windows tasks, auto-push, connect to real trading, or execute orders.

## Honest limits
- Simulated/proxy trading cannot prove real market fills, profit, low latency, maker economics, or generalization. Four one-shot ~75-second captures yield too few nonoverlap 60-second outcomes for a profitable strategy claim.
- A living lifelong evolution system additionally requires real-time precommit, persistent mutation checkpoints, fair walk-forward model allocation, safe retire/restore and audit logging. V45 is a conservative foundation, **not** completion of all of those capabilities.
- Existing six genotypes are evaluated; theoretical 6^5=7,776 genotype combinations are not all executed.
