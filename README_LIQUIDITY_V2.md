# 哥白尼流动性研究 V2

本版在四品种、300/900秒预测和共享10美元虚拟资金研究器上增加公开强平快照、标记价、指数价、资金费率和持仓量，以及盘口消耗、补单与主动成交压力。研究模型不识别交易者身份，不把未公开止损单当作已知数据。

## 数据与学习

- Binance强平流每品种每1000毫秒仅提供最新一笔快照，并非全部强平。按事件去重，使用最后成交数量`l`和均价`ap`计算观察到的名义量，不反复累加累计数量`z`。
- 盘口仅在相邻快照共同可见的价格范围内比较；窗口外价格未知。净减少不能单独区分撤单与成交，补单不代表同一做市商。
- 标记价和OI分别检查接收时间与交易所时间。缺失、过期、断线丢弃受影响未成熟样本，不把缺失填成真实零值。OI是持仓总量，无法还原每个人开仓价、保证金和杠杆。
- 四组同架构模型比较：原始特征、加入流动性、去掉强平特征、冻结参数。预测先提交，300/900秒标签成熟后学习；不从未来标签回填特征。
- 对照输出配对Brier损失与成本后报价代理。描述性误差界没有做多重选择校正；少量样本不构成正收益证据。流动性影子模型不自动取得下单权限。
- 主研究器在标记价不新鲜时不模拟开新仓；对将跨越尚未对账资金费结算的计划持仓也拒绝开仓。该门控不能替代实盘资金费、排队与成交核算。
