## 页面可操作内容

- 一键启动自动模拟：采集 BTC、ETH、SOL、BNB 公共五档盘口，显示实际报价曲线，更新独立树突节点。
- 手动模拟：先选择手动模式并点击启动，再选品种、金额和做多/做空。已有持仓可单独平仓。
- 暂停开仓：停止新增持仓；已有持仓仍监测止损、止盈、最长持仓和回撤。
- 全部模拟平仓：核对所有持仓报价后统一退出，同时暂停开仓。
- 查看模拟净值、手续费、持仓、交易记录、观望原因、历史学习覆盖和未来事件。

自动模式分别记录未验证的小额探索和通过描述性门槛的模拟策略，不保证启动后就有交易。
小额探索采用净值5%的保证金、10倍名义仓位，最多同时一笔；同币两次探索建仓至少间隔十分钟。
合约持仓不按五分钟或十五分钟到期退出。五分钟只负责预测标签核对，独立于持仓生命周期。
当前激活的统一策略为COPERNICAN_MARKET_EVENT_V1，参见 `reports/copernican_market_event_build_20261016.md`。
它以主动成交、盘口消耗/补单、突破反应、资金费/OI及抽样强平检验流动性延续/吸收等假设，叠加全球消息与已知发布窗口约束。
探索必须先有至少60秒连续报价，近最多五分钟的区间超过14bps费用假设+当前价差+4bps缓冲，净方向变化至少8bps。
这些是事前固定的实验条件，不是预测未来收益；过去波动够大不代表下一段一定能覆盖成本。
事件拦截、报价新鲜度、保证金限制、止损和账户回撤限制仍生效。探索不会把未验证节点标为合格。
盘口节点以实际采样的价格变化、五档数量失衡、价差和一档数量失衡作为四个特征，其余树突输入明确置零。
只对有观测输入的树突分支求预测及梯度，避免三个全零分支把输出和梯度稀释四倍。
节点使用五分钟延迟标签，保存参数、待核对预测与过去评分。停机错过标签超过30秒时丢弃，不将历史补课冒充实时预测。
同时记录涨、跌和成本区间内横盘的结果；模型暂不判断（UNCERTAIN）不等于已经预测横盘。
节点至少100个达到方向阈值的成本代理样本、均值减三倍标准误为正且概率评分优于0.5基准，才可取得**模拟**策略资格。
上述100样本门槛仅用于验证策略。探索交易不等待它，但以PAPER_EXPLORATION单独记录，不构成盈利证明，也不是实盘准入。
页面“当前交易判断”显示各币的模型分数、验证样本计数、实际区间/成本缓冲及控制器执行状态。

事件前瞻模块同线程运行；临近已登记事件可拦截自动模拟开仓。支持 `python -m cqwe.workbench --book-state <state.json>` 接入原盘口委员会的有效新鲜状态。
默认低频节点仅取约5秒一次的公共REST快照，不能重建连续订单流、确定做市商意图或识别全部止损。

## 模拟账户规则

初始虚拟资金10 USDT，固定10倍全仓模拟；手动输入金额为保证金，名义仓位=保证金×10。
单币保证金最多净值25%，总保证金最多50%。例如2 USDT保证金对应20 USDT名义仓位。
买入按卖一加2bps滑点，卖出按买一减2bps滑点；每边0.05%手续费按名义仓位计算。
账户可用保证金、名义仓位和每笔杠杆独立记录。价格止损仍为0.30%、止盈0.60%，并非保证金收益率阈值。
增加模拟保证金不足退出：按当前仓位价值1%的固定维持保证金假设，加预估退出费用进行检查。
这不是币安实际强平模型，未取得账户档位及标记价强平数据。真实维持保证金率随品种和档位变化，参见[币安官方说明](https://www.binance.com/en-AE/support/faq/detail/360033162192)。
全仓亏损可能波及其他仓位；极端跳空允许记录负余额，不虚构“止损一定成交”或“亏损必定封顶”。
价格硬止损30bps保留；固定60bps止盈取消，趋势延续时可以继续持仓。
两根反色K线的退出规则已退役。当前机制退出要求相反方向成交与流动性假设连续确认，数据新鲜、完整且证据达到预设强度。
事件标题不直接提供涨跌方向，也不能单独触发平仓。做市商意图未知，缺失源不当成已证实的数据。
盈利方向的最大价格收益达到40bps后启动移动保护，从最佳可平仓报价回撤20bps则退出。价格跳空可能使实际收益更差。
回撤达10%停止新开仓并在有效报价可得时退出；保证金不足退出和手动退出继续生效。
上述反转/移动阈值为预先定义的待验证实验规则，不能证明识别了真实拐点或保证盈利。
网络中断时不会按过期报价伪造平仓。价格跳空、轮询延迟可能使损失超过止损阈值。
自动退出后等待五分钟再评估同品种；手动可主动重新建仓。
模拟数量没有核对交易所最小下单量，资金费和容量影响尚未计入。
