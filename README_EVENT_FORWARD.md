# 哥白尼事件研究与前瞻学习

本模块使用 BTC、ETH、SOL、BNB 的公共数据，运行时间有上限，默认 60 秒。
研究流程为：保存日历来源 → 事件时刻首次可用报价与预测留档 → 5/15/60 分钟后核对报价 → 计分 → 更新独立树突节点 → 保存检查点。

```powershell
.\RUN_COPERNICAN_EVENTS.ps1 -Seconds 60
```

程序单进程、较低优先级，空闲时不查询行情；仅事件窗口与待成熟预测需要报价。
SQLite 事务使结果、参数和学习日志一起保存。重启后先重放核对日志、原预测和模型参数；成熟时间错过超过 30 秒的样本丢弃，历史补课留在历史研究库。
源码或费用配置改变时必须使用新的 Root，旧结果保持原样。磁盘剩余不足 1GB 或研究数据库超过 100MB 时停止。
本轮没有恢复登录启动、常驻研究或旧计划任务。

## 数据与预测含义

日历包含原有宏观数据、八家央行、三个会议开幕日，以及新增工业产出、住宅建设、新屋销售、M3 订单、ISM 两项 PMI。
住宅建设和 M3 日历可能同时包含初值、后续发布和修订，阶段未核实；日期条目不等于独立经济冲击。
新增 ISM 仅有官方 2026 日历，2025 尚缺失。直接访问遇到 403，2026 表来自网页工具读取的官方页面，保留结构化提取与来源。
新日历文件 `reports/macro_watch_plan_expanded_20261016.json` 覆盖生成时随后 60 天，是保存的快照，运行中不会自动刷新。
FRED 部分 2024 请求只返回 2025 年起的数据。已提取的事件值和事前一致预期也不完整。

前瞻树突节点当前使用事件类型、事件之前已收盘的价格变化和时间特征；尚不具备完整的宏观惊喜值、新闻语义和政治事件实时判断。
历史节点和前瞻节点参数独立。历史预测检验使用时间顺序训练/验证/留出集，参数与策略选择不读取留出结果。
零收益、方向正确、低 Brier 分数均不能证明盈利。

## 统一建议接口

`cqwe.event_council_bridge.combine` 接收现有盘口委员会建议和事件前瞻状态。
未通过独立成本验证的事件节点始终零权重。临近已知数据发布 30 分钟或事件状态缺失/陈旧时，可把开仓建议变为 WAIT；不会覆盖 CLOSE/HOLD。

```powershell
.\RUN_COPERNICAN_EVENTS.ps1 -Seconds 60 -BookState 'D:\路径\state.json'
```

BookState 必须为校验和有效、决策时间距离当前不超过 10 秒的盘口委员会状态。过期输入仅输出观察与错误记录。
合并建议写入事件运行目录的 `status.json`，现有盘口引擎的模拟成交规则尚未消费此合并结果。
模块没有账户连接、下单接口或实盘交易资格。

## 费用和限制

前瞻结果以真实买一卖一计算价格接受者收益代理，再扣双边手续费合计 10bps 和额外滑点合计 4bps。
资金费、可成交数量、真实成交、限价排队与跨平台结算不在此代理中，因此不能据此直接升级实盘。
历史策略验证仅扣固定 14bps，缺少历史盘口，进一步弱于可执行回测。
风险过滤尚未覆盖全部突发事件，ETF、战争、黑客等来源没有全部实时接通。
本模块只自动更新有边界的模型参数；不会自动改写源码或发布未经验证的新策略。
